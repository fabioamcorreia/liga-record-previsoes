# Liga Record – Previsões

App para prever os pontos da Liga Record em cada jornada e escolher o onze, o capitão, os suplentes, o treinador e a transferência da semana. Funciona no PC (abrir `index.html` no Chrome) e no telemóvel (site no GitHub Pages, instalável no Android).

## Uso semanal (no PC)

1. **Pontuações:** guarda o email "Liga Record - Pontuações" em PDF na pasta `pdfs/` e carrega em **Pontuações → Atualizar**.
2. **Sofascore:** carrega em **Sofascore → Atualizar** e, no separador que abre, clica no marcador **Liga Record ⚽** (ver "Como usar" na app para o criar).
3. Confirma o **Plantel** (jogadores, preços, saldo) e vê **O meu onze** e as **Transferências**.
4. **Telemóvel → Publicar** e depois duplo clique em `publicar.bat`. Em 1-2 minutos o telemóvel fica atualizado.

## No telemóvel (Android)

Abre o site no Chrome → menu ⋮ → **Adicionar ao ecrã principal**. Ao abrir, a app vai buscar os dados publicados a partir do PC.
